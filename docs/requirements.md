# 需求与范围

## 一句话需求

用 Vue 3 实现一个可公网访问的咖啡店网站（纯前端，3 个页面，正好 15 个单文件组件），
代码保持简单、可逐文件讲解，并覆盖 <https://cn.vuejs.org/tutorial/> 的核心知识点。

## 硬约束与落地

| 约束 | 落地方式 |
| --- | --- |
| 任选主题、只需前端 | 咖啡店官网与购物车，无后端接口、无数据库、无真实支付 |
| 至少 3 个页面 | 首页 `/`、菜单 `/menu`、购物车 `/cart`；未知路由回首页 |
| 15 个单文件组件 | 1 个 `App.vue` + 3 个页面 + 11 个可复用组件，共 15 个 |
| 覆盖教程知识点 | 教程第 1–14 步逐项有落点，见 `README.md` 对照表 |
| 可公网访问 | `netlify.toml` + `public/_redirects`，构建产物 `dist/`；仓库本身不带线上地址，需自行部署后填入 |
| 报告与 PDF | 两份文件在**上一级目录** `D:\Github\Work\`（项目根没有），是先前版本，按最新要求**不修改** |

## 页面功能

1. **首页**：主视觉、本周推荐、粉水比计算器（滑块 + 计算属性）。
2. **菜单**：6 款咖啡、关键词搜索、分类筛选、商品详情弹窗、加购。
3. **购物车**：数量增减、删除、金额汇总、收货信息校验、下单成功提示。

## 明确不做

- 后端、数据库、登录注册、真实支付。
- 独立商品详情页、关于页、404 页面组件：详情改为菜单页弹窗，未知路由直接回首页。
- 用户上传、多语言、暗色主题、组件库。
